Monitoreo inteligente de sistemas solares modulares

Plataforma web para energía solar rural, diseñada para decisión, mantenimiento y escala.

Este prototipo funcional TRL5 integra dashboard energético, telemetría IoT simulada, alertas, nodos, analítica y validación funcional para apoyar la gestión de sistemas solares en zonas rurales.

Caracterización de la muestra

Muestreo intencional por criterio

La validación piloto académica se consolidó con 20 participantes anonimizados: 12 usuarios potenciales de sistemas solares, 5 perfiles técnicos o instaladores y 3 actores académicos relacionados con energía o desarrollo de software.

Validación del instrumento

Encuesta semiestructurada

  • 10 ítems: 7 cerrados tipo Likert y 3 abiertos.
  • Revisión de claridad, pertinencia y coherencia con objetivos.
  • Aplicación orientada a necesidades de monitoreo, alertas, uso móvil y diagnóstico energético.
  • Resultados usados para priorizar requerimientos funcionales del prototipo.

Necesidades priorizadas
